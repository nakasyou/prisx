# 実装状況

受領仕様: v1.0 / 2026-09-06。第13章は途中で途切れている。

## 実装・ローカル検証済み

- Bun、Solid、CodeMirror 6、暗色／明色のリボン・左右サイドバー・タブ・Markdownライブプレビュー／ソース切り替え（CodeMirror維持、ユーザーの追指示により変更）。
- Better Auth のメール／パスワード認証、個人ワークスペースの初期化、複数ワークスペース切替。
- 認証・workspaceId を確認するエンティティ／本文／検索／グラフ／履歴／エクスポート API。
- 不変エンティティ ID、同名 item、別名、論理削除、キーとタグの同名制御、予約名前空間。
- 型付き再帰 Value、独立 Statement、同一キー・同一値の複数主張、独立リビジョン、fingerprint。
- 有効時間、ランク理由、精度・タイムゾーンを保った三値判定、期間適用後の複数代表値解決関数。
- 共有 JSON Schema 検証、strict 化前の既存主張検証、class 必須／許可キー、複数親の探索、継承循環拒否。
- 支持／反証／文脈の Evidence、出典コンテンツ版・ページ、主張の確からしさ評価と根拠。
- 意味を変える編集後に以前の評価・証拠を自動流用しないこと。
- Markdown AST タグ抽出、コード／frontmatter／URL／コメント等の除外、NFC・ASCII正規化。
- 本文版・派生タグ／リンク・全文索引を同じ SQLite トランザクションで確定。
- 明示タグと本文由来タグの和集合。明示タグの削除は本文を書き換えない。
- CodeMirror の安定した lifecycle、800ms自動保存、IME制御、補完、独立本文保存。
- expectedRevision、409、本文の競合比較・手動統合、IndexedDB 本文下書き。
- 構造化ソースの複数行をトランザクションで適用。失敗時は全行ロールバック。
- 任意ファイル保存、画像／音声／動画表示、PDF.js Worker＋CanvasによるPDF表示、未知形式の取得。
- 認可済みルートの Range 応答、不変コンテンツ版、SHA-256、idempotency key。
- file-storage の不変確定、fsync、パストラバーサル／シンボリックリンク拒否。
- FTS5 trigram 索引、短い日本語検索フォールバック、基本 `tag:` / `type:` / `class:` / `has:` 検索。
- 保存済み検索の Query AST 保持、Canvas グラフと Worker レイアウト、バックリンク。
- 本文履歴から新リビジョンを作る復元、削除状態・全版・元ファイルを含むエクスポート。
- 別 DB の空ワークスペースへの再インポート。ID・レコード・履歴・バイト列の一致をテスト。

## 実装済み・外部環境では未検証

- s3-compat の Put/Get/Head/Delete、設定による切替、書込み後の独立 SHA-256 照合。
- Wikidata の Q ID 手動取り込み。JSON 本体と元 statement を opaque 値として保持。外部障害は取り込みにのみ影響。

## 仕様全体に対して残る作業

- 頻度の高い検索向けの専用派生値索引、永続ジョブ、マイグレーションの複数バージョン運用、明示的な relational adapter 契約型。
- 全制約（代表値／同時点 cardinality、referenceClass、uniqueness、contextKeys、必須評価、qualifierRules）とスキーマGUI。warn の行単位表示、登録済み版固定スキーマ参照、制限付き正規表現。現在、正規表現と外部 `$ref` は拒否する。
- class 変更で全影響エンティティを再検証する完全な事前解析。必須キーをまとめて導入する移行手順、クラス制約の矛盾診断。
- データ欄の IndexedDB／サーバー下書き、値ごとの自動保存。現在はフォームの保存操作で確定。
- 辞書・配列のGUI編集とエンティティへの展開。表示は再帰対応、編集は型を保持する構造化JSON。
- Source reliability / Evidence strength 評価の編集UI、独自尺度、全locator、証拠・評価のID単位編集／削除、旧版証拠の再確認UI。
- タグ統合・本文の差分つき一括改名、本文由来タグから出現箇所への移動。
- 通常の `[[タイトル]]` の選択／未解決解消と埋め込み。ASTでは取得するが、ライブプレビュー内のリンク遷移・埋め込みは未実装。
- 同じStatement／Evidenceに対する高度な条件ビルダー、辞書内部パス・型付き比較、複数タグAND/OR GUI、検索結果の本格的なテーブル。
- グラフの辺クリック、細かなフィルタ、Statement中間ノード、上限後の追加展開、パン操作。
- 任意エンティティの汎用ペイン分割、ショートカット再割当、タブ配置の永続保存。現在はCodeMirrorのライブプレビュー／ソース切り替え。
- ストリーミングのオブジェクト転送、ステージング状態管理、quota、孤立オブジェクト回収、保持管理、S3契約テスト／multipart／署名URL。現状アップロードは上限100MiBのバッファ方式。Range 応答でもオブジェクト全体を読む。
- MIME検出の拡充、メディアデコード失敗時の状態表示、JSONエディター言語拡張、抽出・サムネイルジョブ。
- 大規模アーカイブの分割／ストリーミング復元、バックアップ中の保持保証、アダプタ間オンライン移行。
- 復元・削除UIの対象拡大、バイナリ競合の選択UI、接続復帰時の自動再送、実機IME試験、スクリーンリーダーとフォーカストラップの監査。

この一覧は未実装項目を完成済みと見せないための記録であり、仕様変更の提案ではない。
